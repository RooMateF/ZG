# 初版工作清單：住宅區的第一棟房子

2026-11-18 建立。這份是三方共用的清單：做完一項就把 `[ ]` 改成 `[x]`。美術的進度仍以 `docs/ART_TRACKER.md` 為準，這裡列的是「初版需要哪些」。

每一節標了「定案」「預設」「提案」。提案是 Claude 的估算，品項、尺寸、數量都可以改；風格由使用者和美術總監決定。

---

## 一、初版是什麼（定案：使用者 2026-11-18 同意）

文字版開局的那棟房子，做成可以從頭玩到尾的一段。

- **地點**：住宅區的一棟透天厝，加門口的巷子。
  - 一樓：客廳（可當據點，有樓梯）、廚房（有水）、臥室（陳水木躲在床底下）、車庫（上鎖）
  - 二樓：主臥（可當據點）、小孩房、浴室（有水）
  - 三樓：閣樓（很暗）
- **內容**：第一天。進屋、搜東西、遇到陳水木、打兩三場、封門過夜，天亮結束。約二三十分鐘。
- **不包含**：其他地區、勢力、三條出路、結局、第二天以後。

初版的目的是把所有機制在一棟房子裡做出來（`docs/GAME_DESIGN_HD2D.md` 第二節「建造順序」的第一圈）。

## 二、美術（提案：品項和尺寸）

**換算方法**：原生像素數 ≈ 真實公分 ÷ 2。這已經包含 1.35 倍（189 公分的沙發 → 94 像素）。下面的尺寸都是「寬 × 高 × 深」的像素數，寬是面向鏡頭的那一面。

**交付方式**和這次的客廳家具相同：方塊家具交 `_front`、`_top`、`_side` 三張；有高低差的拆成幾件；形狀不規則的交透明底單張（立牌）。不靠牆、玩家會繞到後面的，多交一張 `_back`。

### 4. 角色

初版裡會出現的人：許晏、陳水木、行屍、疾走者（中途闖進來的那一隻）。沈以美不在初版出場，照文字版她在第二圈的藥局（定案，使用者 2026-11-18）。

| 角色 | A 轉身 | B 走路 | C 戰鬥 | D 立繪 |
|---|---|---|---|---|
| `hero` 許晏 | 有 | 缺 | 缺 | 有 |
| `chen` 陳水木 | 有 | 缺 | 缺 | 缺 |
| `walker` 行屍 | 有（32 種） | 缺 | 缺 | 不需要 |
| `runner` 疾走者 | 有 | 缺 | 缺 | 不需要 |

- [ ] `hero` 的 B、C
- [ ] `chen` 的 B、C、D
- [ ] `walker` 的 B、C：2 到 4 種外觀（定案，使用者 2026-11-18），挑哪幾種由美術總監決定
- [ ] `runner` 的 B、C

規格在 `docs/ART_DIRECTOR.md`「每個角色要的四組圖」。

**要美術總監先想的問題**：行屍有 32 種外觀，每種都畫走路和戰鬥是 64 張連續格，不實際。初版只出場 2 到 4 種，其餘先不出場。長期怎麼辦（共用身體動作只換衣服、或只留少數幾種），請美術總監提意見，這部分還沒定。

B 生不出來的退路還在：現在場景裡用的就是程式做的暫代走路。C 沒有退路，沒有圖就只能用閃白和位移代替。

### 7. 音效和音樂（定案：先用免費素材庫，使用者 2026-11-18；品項是提案）

由 Claude 從免費素材庫找。每個檔案的來源和授權條款要記下來，只用可以放進遊戲、不要求付費的。

聲響是這款的玩法，沒有聲音會少一大半。初版大約需要三十個音效：

- 腳步：木地板、磁磚、水泥、柏油，各分走和跑
- 門：開、關、鎖著打不開、撞門
- 搜索：翻抽屜、翻櫃子
- 封門：敲釘子
- 環境物：玻璃碎、丟出去的東西落地、開關燈
- 敵人：行屍平常的聲音、發現人、攻擊、倒下；疾走者的叫聲
- 打擊：鈍器、刀、受傷
- 介面：選擇、確認、取消
- 環境音：夜晚的室內、巷子的風
- 音樂：探索、戰鬥、安全的據點，各一段

## 三、程式（預設：照這個順序做，每一項做完都看得到結果）

**房子**

- [ ] 把測試房間縮到合理大小，調回夜晚的氣氛
- [ ] 多個房間用牆和門接起來，鏡頭跟著人走
- [ ] 進屋時屋頂和靠鏡頭的牆淡出
- [ ] 三層樓和樓梯，只顯示目前這一層
- [ ] 巷子和大門
- [ ] 暗的房間（閣樓）：沒有手電筒只看得到身邊一圈

**規則和畫面接起來**

- [ ] 定 Python 規則和 Godot 之間的溝通格式（`docs/GAME_DESIGN_HD2D.md` 第十節）
- [ ] 時間改成照走的距離和做的事前進
- [ ] 物資從「搜房間」改成分散在櫃子抽屜裡，總量不變

**探索**

- [ ] 走和跑，聲音半徑看得見
- [ ] 行屍聽到聲音會走過來
- [ ] 開門、關門、貼門聽、上鎖的門（車庫）
- [ ] 翻櫃子抽屜，背包介面
- [ ] 丟東西引開、開關燈、躲藏
- [ ] 封門窗
- [ ] 叫隊友跟上或留在原地

**戰鬥**

- [ ] 原地開戰，開戰距離就是當時的實際距離
- [ ] 距離帶（貼身、近、中、遠）和前後排
- [ ] 每個人輪流下指令，行動順序列
- [ ] 基本指令（設計文件第五節）：攻擊、打頭、打腿、瞄準、推開、牽制、掩護、上前和後退、丟東西和用物品、逃跑
- [ ] 環境指令：關門、推倒家具、躲到家具後面
- [ ] 隊友不聽話（陳水木怯懦，可能逃）
- [ ] 中途闖進來的敵人
- [ ] Python 戰鬥規則改成一個單位一個回合，重新平衡數值，補測試

**其餘**

- [ ] 狀態列：生命、飢餓、口渴、體力、時間
- [ ] 日夜的光
- [ ] 遇到陳水木的對話、收他入隊、隊友跟在後面
- [ ] 過夜：睡覺、守夜、夜襲
- [ ] 存檔（每天早上）、死亡、標題畫面
- [ ] 天亮時的結束畫面
