# 素材進度表

由美術總監維護。每一格的狀態：

- 空白：還沒開始
- `生成中`：使用者正在生圖或調整
- `待匯入`：審過了，圖已放進 `hd2d/art/inbox/`
- `已匯入`：工程已放進遊戲（由 Claude 改）
- `退回`：匯入時發現問題，原因寫在 `docs/handoff/eng_to_art.md`

四組圖的定義見 `docs/ART_DIRECTOR.md`。
