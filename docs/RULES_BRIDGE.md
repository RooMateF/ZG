# 規則和畫面的溝通格式

2026-11-18 建立。這份說明 Godot（畫面）怎麼跟 Python（規則）講話。程式在 `zg/hd/`，測試在 `tests/test_hd.py`。

**狀態**：規則這一側做完了，有 38 項測試。Godot 那一側還沒接上，所以整條線還沒有實際跑過。數值都是起始值，沒有人玩過。

---

## 一、原則（定案，來自 `docs/HD2D_PLAN.md`）

- Python 當裁判。畫面只做兩件事：送出指令、拿回事件和狀態。畫面不直接讀規則內部。
- 位置、碰撞、誰聽到了誰，歸畫面。時間、飢渴、命中、傷害、物資、信任，歸規則。分工表在 `docs/GAME_DESIGN_HD2D.md` 第十節。
- 文字版（`zg/` 其他檔案）不改，使用者還在玩。HD-2D 的規則放在 `zg/hd/`，只借用文字版的資料表和狀態結構。

## 二、怎麼啟動（預設）

Godot 把規則開成子程序，用標準輸入輸出講話：

```
python -X utf8 -m zg.hd.bridge
```

- 一行一個 JSON 送進去，一行一個 JSON 回來。UTF-8。
- 第一個指令要是 `new` 或 `load`。
- 規則出錯時回 `{"ok": false, "error": "...", "trace": "..."}`，程式不會停，畫面不會卡住等回覆。

打包成執行檔時要把 Python 一起包進去，這件事還沒做。

## 三、回覆的樣子（預設）

每個指令都回這幾樣：

| 欄位 | 內容 |
|---|---|
| `ok` | 成不成立。不成立時狀態不變，`error` 是可以直接顯示的中文 |
| `events` | 這個指令引發的事，照發生順序。畫面照這個播動畫和訊息 |
| `state` | 現在的整體狀態：第幾天、時鐘、所在房間、地區威脅值、玩家的血量飢渴體力背包、隊友、據點 |
| `battle` | 戰鬥中才有。見第六節 |
| `room` | `new`、`state`、`enter`、`take`、`load`、`text` 會附上目前房間的內容 |

事件一律有 `t`（種類），有話要顯示時有 `text`。其餘欄位照種類不同，畫面只要認得 `t` 就能決定播什麼。

## 四、探索的指令（預設）

| 指令 | 參數 | 作用 |
|---|---|---|
| `new` | `seed`、`difficulty`（normal／hard）、`goal` | 開新局 |
| `state` | | 只拿狀態，不做事 |
| `enter` | `room`（例如 `住宅區·廚房`） | 玩家走進這個房間。第一次進去時把物資分進容器。鎖著的回錯誤 |
| `walk` | `dist`（走了幾個單位）、`run` | 推進時間：每 2.5 個單位 1 分鐘。跑步扣體力。回 `noise` 和 `radius`（腳步聲的半徑） |
| `noise` | `action`（door、door_slam、search、pry、glass、topple）或 `amount` | 弄出聲音。加進地區威脅值，回半徑 |
| `search` | `container` | 翻一個容器。花時間、有聲音。裡面藏著東西時回 `ambush` 事件，不花時間 |
| `take` | `item`、`qty`、`container`（不給就是拿地上的） | 拿東西進背包 |
| `text` | `line` | 借用文字版的指令（吃東西、加固、睡覺、交談、製作）。這些之後會一個一個改成專用指令 |
| `save`、`load` | `path` | 存讀檔。路徑一定要給，而且不能是文字版的 `save.json` |

**站著不動時鐘不走。** 畫面沒有回報 `walk`、`search`，時間就不會前進。

**聲音怎麼接**：規則回半徑，畫面拿這個半徑去找範圍內的敵人，讓牠們朝聲音走過去。牠走進戰鬥圈就送 `battle_start` 或 `battle_join`。

**規則引擎自己叫來的敵人**：地區威脅值到門檻時，規則會在目前的房間加敵人，並回一則 `intrusion` 事件列出牠們。畫面要讓牠們從地區邊緣走進來。戰鬥中也一樣：規則只通知，牠們什麼時候走進戰鬥圈由畫面決定，到了再送 `battle_join`。

**沒發現玩家的敵人不會自己加入戰鬥。** 開戰時只有 `foes` 裡列的那幾隻在打，同一個房間裡其他的照常待著。

## 五、房間和容器（預設）

`room` 的內容：`id`、`name`、`tags`（street、dark、water、stairs、locked……）、`exits`、地上的 `items`、`containers`、`enemies`、`people`（還沒入隊的生存者）。

每個容器有 `id`、`name`、`furniture`、`minutes`、`noise`、`opened`。`furniture` 是家具代號，和 `docs/FIRST_BUILD.md` 第二節一致，畫面靠它把容器接到家具上。沒翻過的容器不透露內容；隊伍裡有搜索技能的人時多一個 `hint`，說裡面有沒有東西。

物資總量和文字版一樣，只是分到各個容器裡。街道沒有容器。住宅區八間房的容器已經排好，其他地區先用通用的三個（櫃子、抽屜、角落）。

## 六、戰鬥（預設）

### 開戰和加入

| 指令 | 參數 |
|---|---|
| `battle_start` | `foes`、`opener`、`env` |
| `battle_join` | 一隻敵人，欄位和 `foes` 裡的一樣 |
| `battle_act` | `unit`、`act`、`args` |
| `battle_view` | 只看，不做事 |

`foes` 裡每一隻：`uid`（房間內容裡的編號）、`room`（不在目前房間時才要給）、`dist`（開戰那一刻離玩家幾個單位）或 `band`（直接給距離帶）、`via`（牠要從哪扇門進來，對應 `env` 裡門的 `id`）、`sprite`（畫面用的圖，例如 `walker_police_01`）。

`opener`：`enemy` 是牠先發現你，牠們第一回合先動；`player` 是你先動手，你們第一回合先動，每個人帶一級瞄準；其餘是 `neutral`。

距離換成距離帶：1.5 個單位以內是貼身，3.5 以內是近，6.5 以內是中，更遠是遠。

### 環境物件

`env` 是這個房間裡能用的東西，由畫面列出來：`{"id": "...", "kind": "...", "name": "房門"}`。

| `kind` | 指令 | 效果 |
|---|---|---|
| `door` | 關上、頂住、打開 | 關上後，還在門外（`via` 是這扇門、距離是「遠」）的敵人進不來，只能撞門。門撐 3 下，頂住一次加 2 下，最多 6 下 |
| `topple` | 推倒 | 砸到「近」的敵人並讓牠踉蹌；沒有人在「近」時，擋住更遠的敵人一回合。只能用一次，很大聲 |
| `cover` | 躲到後面 | 人類敵人的槍命中 -25 |
| `choke` | 守住 | 要在前排。一次只有一隻敵人貼得上來 |
| `noise` | 弄響 | 還沒貼身的非人類敵人分心兩回合。只能用一次，很大聲 |
| `fire` | 點燃 | 要有打火機（或物件標 `lit`）。燒「近」和「中」的敵人。只能用一次，很大聲 |
| `light` | 開關燈 | 關燈後人類敵人的槍命中 -20 |

設計文件裡的「拿起來用」（椅子、滅火器）和「翻過去」還沒做。

### 輪流行動

每一回合所有人照速度排一次：疾走者最快，然後是玩家、隊友、人類敵人、行屍，腫脹者最慢。輪到我方的人時規則停下來等指令，`battle.current` 是他的編號，`battle.options` 是他現在能下的指令。

`battle_act` 的 `act`：

| `act` | `args` | 說明 |
|---|---|---|
| `attack` | `target`、`mode`（body、head、legs） | 打頭命中低但一擊斃命；打腿傷害低，但那一隻之後走得慢 |
| `aim` | | 最多疊三級 |
| `push` | `target` | 推開貼身的敵人。自己被抓住時是掙脫 |
| `taunt` | | 牽制。要在前排 |
| `cover` | `target`（隊友） | 替他擋，到自己下一次行動為止 |
| `row` | `row`（front、back） | 換排 |
| `throw` | `item`、`target` | 丟東西引開，或丟燃燒瓶 |
| `use` | `item`、`target`（隊友） | 繃帶、急救包、止痛藥 |
| `env` | `env`、`verb` | 環境指令 |
| `flee` | `exit` | 全隊逃跑 |
| `wait` | | 喘口氣 |

指令不成立時只回一則 `t` 是 `no` 的事件，不耗回合。

### 畫面要顯示的

`battle` 裡每隻敵人有 `band`、`band_name`、`eta`（照現在的速度還要幾回合貼上來）、`steps` 和 `period`（一次走幾段、每幾回合走一次）、`blocked`（被門擋住）、`slow`、`stagger`、`distract`、`vest`、`helmet`。`eta` 就是設計文件說的「牠還有幾步會到」。

每個指令選項有 `ok`、`why`（不能用的原因）、`stamina`、`noise`、`targets`（每個目標的命中率）、`obey` 和 `obey_label`（他會不會聽：會聽、大概會聽、可能不聽、多半不聽）。

每個隊友有 `break_chance` 和 `break_kind`：他這回合自己行動、不等指令的機率和會做什麼。畫面應該在行動順序列上先標出來，不要讓玩家覺得是暗骰。

### 隊友聽不聽（提案的數值）

- 只有危險的指令可能被拒絕：上前、牽制、掩護、守住門口。
- 聽的機率 = 30 + 信任 × 0.5 − 超過 40 的恐懼 × 0.5。怯懦再 −20。
- 忠誠的人和有羈絆的人一定聽。冷酷的人不掩護別人。
- 拒絕時他會說一句話，然後照自己的判斷行動。
- 性格發作（輪到他時擲一次）：怯懦的人在血量低於一半、敵人三隻以上、或恐懼 70 以上時，四成以上機率躲起來，打完才回來；貪婪的人在有屍體可翻時 35% 去翻，掉的東西進他的口袋；實際的人在寡不敵眾或血量低於四成時 50% 自己退到後排。

## 七、主要的數值（起始值，沒有玩過）

| 項目 | 數值 |
|---|---|
| 走路的時間 | 2.5 個單位 1 分鐘 |
| 跑步的體力 | 每個單位 0.5 |
| 聲音半徑 | 音量 0.25 是 1.5 個單位，0.5 是 3，1 是 5，2 是 8，3 是 12，4 是 25，5 是 40 |
| 腳步聲 | 走路 0.25、跑步 2。每多一個隊友 +25%，很累時 ×1.3 |
| 武器在各距離的命中修正 | 近戰武器只打貼身。消防斧打得到近（−20）。霰彈槍：貼身 −5、近 0、中 −20。手槍：貼身 −10、近 −5、中 0、遠 −20 |
| 敵人每回合走幾段 | 行屍 1、疾走者 2、腫脹者每兩回合 1 |
| 打腿 | 傷害減半，命中 −10。每打中一次少走一段；已經只走一段的改成隔一回合才走 |
| 敵人的外觀 | 圖檔名含 `police` 的有防彈背心（打身體傷害減半），含 `dock` 的有安全帽（第一次打頭只打掉安全帽） |

命中、傷害、被咬、感染的數字沿用文字版的資料表（`zg/data.py`）。

## 八、還沒做的

- Godot 那一側：開子程序、送指令、照事件播動畫。
- 把 Python 一起打包。
- `text` 借用的那些指令（過夜、加固、交談、收人、製作）改成專用指令和專用事件。
- 設計文件第五節的技能指令（重擊、包紮、翻找、警戒）、環境指令裡的「拿起來用」和「翻過去」。
- 貼著門聽、躲藏、設定會響的東西，這些探索動作在規則這一側還沒有對應的指令。
- 每天早上的存檔點、死亡後的處理。
- 平衡。隨機亂按 120 場的結果是贏 37、逃 51、死 32，只能說明規則不會壞，不能說明好不好玩。
