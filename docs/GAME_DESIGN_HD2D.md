# HD-2D 版玩法設計

文字版的規則在 `DESIGN.md`，數值以那份為準。這份寫的是 HD-2D 版和文字版**不一樣**的地方：地圖、遇敵、戰鬥、搜索、人物。

起因（2026-11-18）：文字版一個房間是一行描述加一個「搜索」指令。HD-2D 的一個房間是玩家要站在裡面走動的地方，同樣的內容攤到畫面上會是空的。所以內容和機制要重談。

每一節標了狀態：

- **定案**：使用者決定的，要改請先問。
- **預設**：Claude 提的做法，使用者看過沒有反對，照這個做，但還能改。
- **提案**：還沒人點頭，寫出來等討論。

| # | 決定 | 內容 |
|---|---|---|
| 1 | 一局的形狀 | 十四天一局、可重玩。地圖固定手工做，物資、敵人位置、目標每局隨機。一般難度每天早上有存檔點，永久死亡留給困難模式 |

## 二、城市地圖

### 排法（定案：15 區全做、一張圖）

沿用文字版的格子，3 欄 7 列。中間一欄是貫穿全城的南北向大路，每一列有一條東西向的橫街。

```
                     軍方檢查站
                     高速公路
        公園         住宅區         學校
        醫院         十字路口       警局
        藥局         商店街         超市
        教堂         加油站         辦公大樓
                     河岸碼頭
```

北邊是出城的路，南邊是汐河出海口。主角從住宅區的租屋處開始。

### 大小（預設，起始值，要在有顯示卡的電腦上走過才能定）

| 項目 | 起始值 |
|---|---|
| 一個地區的街廓 | 約 50 × 40 個場景單位（約 60 × 48 公尺） |
| 走過一個街廓 | 15 到 20 秒 |
| 全城從最北走到最南 | 約兩分鐘 |
| 一個房間 | 6 × 5 到 12 × 7 個單位，照用途 |

這個比例是「模型城市」，不是真實比例。真實的小城走一趟要半小時，遊戲裡沒有人想走。

**家具的比例（定案）**：小人是三頭身，頭很大，真實尺寸的家具站在旁邊像玩具。所以家具、門、窗、樓梯都照真實尺寸的大約 1.35 倍畫。像素密度不變（一像素約 2.7 公分），是畫的像素數變多：真實 189 公分寬的沙發，從 70 像素畫成 94 像素左右。

|---|---|---|---|

| 公園 | 5 | 1F | 多半是戶外 |
| 學校 | 8 | 1F～3F | |
| 醫院 | 11 | B1～3F | 最大的一棟 |
| 十字路口 | 3 | B1～1F | 救護車、公車亭、地下道 |
| 警局 | 6 | 1F～2F | 勢力據點 |
| 藥局 | 5 | 1F～2F | |
| 商店街 | 7 | 1F～2F | 騎樓下一整排店面 |
| 超市 | 8 | B1～2F | |

### 進建築和上下樓（預設）

- **進門**：屋頂和靠鏡頭那面牆淡出，像打開娃娃屋。走出去再淡回來。
- **樓層**：樓層是真的疊在一起的。畫面只顯示玩家所在的那一層，上面的樓層隱藏。走上樓梯時，新的一層淡入。
- **地下室**：一樣的做法，往下走時地面層淡出。
- **暗的房間**（文字版標 dark 的）：沒有手電筒就只看得到身邊一小圈。

### 套件（預設）

89 間不可能每間獨立畫。用七套家具和貼圖拼：

| 套件 | 用在哪 |
|---|---|
| 住家 | 住宅區全部、藥局二樓住家、加油站員工宿舍、船屋、閣樓 |
| 店面 | 便利商店、藥局、五金行、服飾店、小吃店、加油站商店、超市賣場、美食街、漁具店、電器行 |
| 辦公 | 辦公大樓、警局、學校行政、超市辦公室、公園管理室、補習班、網咖、站長室 |
| 醫療 | 醫院全部、診所、牙醫、學校保健室 |
| 學校 | 教室、體育館、圖書館、電腦教室、音樂教室 |
| 街道 | 柏油路、騎樓、鐵捲門、機車、汽車、紅綠燈、公車亭、公園、高速公路 |
| 特殊 | 教堂、碼頭貨櫃區、軍方檢查站、倉庫和地下停車場 |

### 建造順序（預設）

一圈一圈往外做，每一圈做完都是可以玩的：

1. **住宅區**。一棟透天厝八間房加門口的巷子。所有機制先在這裡做出來。
2. **十字路口、商店街、藥局**。第一段街道、第一個生存者（沈以美）。
3. **醫院、警局、學校**。第一個勢力、疫苗目標。
4. **超市、加油站、教堂、辦公大樓**。撤離和護送兩個目標。
5. **公園、高速公路、軍方檢查站、河岸碼頭**。三條出路都通。

### 效能（未驗證）

整張圖都在同一個場景裡，但只有玩家附近的地區開燈、開影子、讓敵人行動，遠的地區休眠。這是不出現讀取畫面的前提。開發機沒有顯示卡，量不出來，第一圈做完要在有顯示卡的電腦上量。

## 三、時間（預設）

文字版每個指令標「耗 N 分」。HD-2D 版改成：

- **走路**：時間跟著走過的距離走，起始值每走 2.5 個單位過 1 分鐘。這樣走到隔壁地區大約 20 分鐘，和文字版的跨區成本一致。
- **動作**：搜索、撬鎖、聊天、加固、睡覺各有固定的時間，沿用文字版的數字再細分（見搜索一節）。
- **站著不動**：時鐘不走，飢渴疲勞也不會漲。但探索是即時的（定案 12），附近的喪屍照樣在動。要停下來想，就開選單暫停。

飢餓、口渴、疲勞、感染、十四天的骨架事件全部跟著這個時鐘，不改。

## 四、遇敵（預設）

### 敵人看得見，沒有隨機遇敵

敵人站在場景裡，會遊走（沿用文字版每小時 6% 換房間的規則，改成真的走過去）。

### 牠們靠聲音找人（聲響系統保留是定案，下面的做法是預設）

設定集寫的是「牠們靠聲音找人，眼睛幾乎沒用」。所以偵測用**聽覺半徑**，不做視野錐：

| 敵人 | 怎麼發現你 |
|---|---|
| 行屍 | 只靠聽。你安靜地從牠旁邊走過去，牠不會動 |
| 疾走者 | 聽，加上晚上在近距離看得到你 |
| 腫脹者 | 只靠聽，反應慢 |
| 人類（掠奪者、士兵） | 用看的，有視野和遮蔽 |

### 聲音是真的

每個動作有一個聲音半徑，半徑內的敵人會朝聲音的位置走過去：

| 動作 | 聲音 |
|---|---|
| 蹲著走 | 幾乎沒有 |
| 走路 | 很小 |
| 跑步 | 中 |
| 搜索、開關門 | 小到中 |
| 撬鎖、打破玻璃、推倒家具 | 大 |
| 開槍 | 整個街廓都聽得到 |

文字版的「沒發現你」是擲骰子（`sneak_chance`）。HD-2D 版改成實際的距離和聲音，原本的修正值變成聲音半徑的修正：隊友越多腳步聲越大、疲勞高時聲音變大。

### 探索時能做的動作（即時行動是定案，動作清單是提案）

戰鬥永遠是指令式的，即時的部分只有「還沒開打」的時候。下面是做得出來的動作，照成本分：

**只要程式，不需要新的圖：**

| 動作 | 作用 |
|---|---|
| 走、跑 | 跑步快但有聲音 |
| 丟東西引開 | 石頭、空瓶丟到指定位置，聽到的喪屍會走過去 |
| 開門、關門、輕輕關 | 關門擋住視線和路。用力關有聲音 |
| 貼著門聽 | 門另一邊有幾個東西在動、離門多遠，用聲波的圖示顯示。不用進去就知道 |
| 推家具擋門 | 開打前先把門堵起來，牠們要多撞幾回合 |
| 開燈、關燈、開手電筒 | 影響人類敵人和晚上的疾走者 |
| 設定會響的東西 | 收音機、鬧鐘、汽車警報。設好就走，等它響把喪屍引過去 |
| 躲進去 | 衣櫃、床底、車底。等一波喪屍走過去 |
| 叫隊友 | 在這裡等、跟上、去搜那個、安靜 |
| 搜索、撿東西、讀東西 | 見第六節 |

**需要美術多畫幾格：**

| 動作 | 作用 | 要的圖 |
|---|---|---|
| 蹲著走 | 幾乎沒有聲音，但慢 | 每個角色一組蹲姿 |
| 翻過櫃台、窗戶 | 捷徑和逃跑路線 | 翻越的動作，或用程式做的跳躍暫代 |
| 從背後無聲解決 | 只對落單、沒發現你的行屍，要有刀。成功就不用開戰 | 出手的動作 |

**即時和回合怎麼接起來：** 開戰時每隻敵人的距離帶，直接用開戰那一刻牠離你的實際距離。你遠遠看到牠就先動手，牠從「遠」開始，你有三四個回合。你被追上才開戰，牠從「貼身」開始。探索時走位的好壞，會直接變成戰鬥裡的回合數。這也是「距離是核心」在探索階段的樣子。

### 地區威脅值還在

文字版每個地區有 0 到 10 的威脅值，到 6 就會湧入一波。這個保留，用來管畫面外的東西：威脅到門檻時，一群喪屍從地區邊緣出現，朝最後一次大聲響的位置走過去。玩家看得到牠們在路上，這段時間可以跑、可以躲、可以關門。

### 怎麼開戰

- **牠發現你**：牠走進「遠」的距離，戰鬥開始，牠先動。
- **你先動手**：對沒發現你的敵人下手，你這邊每個人先動一輪，第一擊有瞄準加成。
- **繞過去**：不進牠的聽覺半徑就不會開戰。

## 五、戰鬥

### 距離是核心（定案）

每一回合玩家在算的是同一件事：**牠還有幾步會到，我在那之前能做幾件事。** 五個變量決定答案：

| 變量 | 它怎麼改變戰鬥 |
|---|---|
| 武器的距離 | 每把武器有它打得到、打得準的距離。刀要等牠貼上來，槍可以在牠還很遠時先開，但會吵 |
| 場景 | 房間大小決定開戰時牠離你多遠。客廳從「中」開始，走廊從「近」開始，停車場從「遠」開始。門、窄道、家具決定牠要多走幾步 |
| 喪屍的速度 | 行屍一回合走一段，疾走者走兩段。變異的更快或更慢。速度決定你有幾個回合 |
| 數量 | 一隻可以慢慢瞄。五隻就算每隻都慢，也沒有足夠的回合處理全部，要靠地形讓牠們排隊 |
| 突然闖入的 | 戰鬥中從門窗進來的增援。牠們從哪扇門進來、落在哪個距離，會打亂你剛排好的順序 |

設計其他東西時的檢查：這個新指令、新敵人、新物件，是不是在改變上面五樣之一？不是的話就先不做。

**武器的距離**（提案，在文字版的射程上加細）：

| 武器 | 打得到 | 最順手 | 備註 |
|---|---|---|---|
| 菜刀 | 貼身 | 貼身 | 安靜、快、省體力 |
| 鐵撬、球棒、釘棒 | 貼身 | 貼身 | |
| 消防斧 | 貼身、近 | 貼身 | 長柄，牠還在「近」就能先砍一下，但命中低 |
| 長柄的臨時武器（拖把桿、曬衣桿綁刀） | 近 | 近 | 新增的一類。把牠擋在一步之外，貼身反而施展不開 |
| 霰彈槍 | 貼身到中 | 近 | 越遠越散。「近」的時候一槍能打到兩隻 |
| 手槍 | 貼身到遠 | 中 | 遠的時候命中下降 |
| 丟的東西（石頭、空瓶、燃燒瓶） | 近到遠 | 中 | |

文字版的數值是近戰射程 1、霰彈槍 2、手槍 3，上表是在這個基礎上分出「打得到」和「最順手」。

**敵人的速度**（變異是提案）：

| 敵人 | 每回合走幾段 |
|---|---|
| 行屍 | 1 |
| 腫脹者 | 1，每兩回合才走一次 |
| 疾走者 | 2 |
| 爬的（提案） | 每兩回合 1 段，但開戰時你看不到牠 |
| 變異（提案，後期出現） | 3，或是會跳過一段家具 |

### 原地開戰（定案）

鏡頭稍微拉近，行動順序列和指令選單浮出來，所有人站在原來的地方。打完選單收起來，直接繼續走。

- **誰在場**：已經發現你的、在一定距離內的敵人，加上你的隊伍。
- **其他敵人還是活的**：戰鬥圈外的敵人照常聽聲音，會走進來變成增援，從「遠」開始。
- **逃跑是往真的門跑**：選逃跑要選方向，成功了戰鬥結束，你站在那扇門外。牠們追不追照文字版的規則。

### 站位（定案：距離帶）

| 元素 | 內容 |
|---|---|
| 敵人的距離 | 每隻敵人各自有一個距離：貼身、近、中、遠（對應文字版的 1 到 4）。牠們每回合照速度逼近 |
| 我方的排 | 每個人在前排或後排。貼身的敵人打前排；前排沒人了才打得到後排。有槍的敵人兩排都打得到 |
| 畫面 | 角色在房間裡照距離站，位置由程式排，玩家不用一格一格走 |

### 輪流行動（定案：每個人都由玩家下指令）

文字版是「玩家動、隊友自動動、敵人動」。HD-2D 版改成每個單位各自輪到，上方的行動順序列顯示接下來誰動。

- 每次輪到做一個動作。
- 體力還是主要資源，沿用文字版的消耗。
- 瞄準、推開、爆頭、牽制、集火全部保留，改成每個隊員都能用。

### 基本指令（預設）

| 指令 | 作用 | 來源 |
|---|---|---|
| 攻擊 | 打身體 | 文字版 |
| 打頭 | 命中低，一擊斃命。先瞄準才準 | 文字版 |
| 打腿 | 新增。傷害低，但那隻之後逼近變慢 | 新 |
| 瞄準 | 可以疊三次 | 文字版 |
| 推開 | 推到「近」並踉蹌一回合 | 文字版 |
| 牽制 | 把敵人的注意力拉到自己身上，其他人打牠有加成 | 文字版，改成前排都能用 |
| 掩護 | 新增。指定一個人，這回合替他擋 | 新，來自羈絆替擋 |
| 上前／後退 | 換排 | 文字版的姿態 |
| 丟東西、用物品 | 石頭和空瓶可以引開，燃燒瓶可以燒 | 文字版 |
| 逃跑 | 全隊，選一扇門 | 文字版 |

### 技能指令（提案）

每個生存者照技能多一個只有他能用的指令：

| 技能 | 指令 |
|---|---|
| 戰鬥 | 重擊：多花體力，傷害高，能打掉安全帽和防彈背心 |
| 醫療 | 包紮：戰鬥中止血、回一點血。看得出誰被咬了 |
| 搜索 | 翻找：在這個房間裡找出一樣能用的東西，多一個環境指令 |
| 守夜 | 警戒：這回合不動，下一個走進「近」的敵人先吃他一擊 |

### 信任和性格決定他聽不聽（定案：會不聽，而且範圍大；下面的細節是提案）

文字版裡，怯懦的隊友會躲起來，貪婪的會偷東西走人。改成玩家下指令之後，這個靈魂要留著，而且要更明顯。

**信任低的時候，任何人都可能這樣：**

- 危險的指令（上前、牽制、掩護）他不做，改成自己判斷。
- 他不做的時候會說一句話，讓玩家知道原因，不是系統故障。

**性格發作（信任低或恐懼高時機率更高）：**

| 性格 | 戰鬥中可能做的事 |
|---|---|
| 怯懦 | 拒絕上前。恐懼夠高時自己逃出戰鬥，躲到隔壁房間，打完才回來 |
| 貪婪 | 敵人倒下後先去翻牠身上的東西，那回合不打。掉落物進他的背包，不是你的 |
| 冷酷 | 不替人擋、不救被抓住的人。有人被咬了他會建議丟下 |
| 實際 | 評估打不贏時自己後退到後排，不管你下什麼指令 |
| 忠誠 | 一定聽。但你叫他丟下別人時他會拒絕 |

**有羈絆的人**什麼都做，還會主動替你擋。

**玩家要看得到機率。** 下指令時選單上標「他大概會聽」「他可能不聽」，不要讓玩家覺得是暗骰在整人。這和文字版把成功率寫在選項上的做法一致。

這樣花時間跟隊友相處有實際的回報，每個隊友也不會變成一樣的棋子。

### 環境指令（定案的方向，內容是提案）

這是原地開戰最大的好處：房間本身是戰場。這些指令只在旁邊有對應的東西時出現。

| 東西 | 指令 | 效果 | 聲音 |
|---|---|---|---|
| 門 | 關門、頂住門 | 門外的敵人過不來，要撞幾回合才破 | 小 |
| 窄的門口、走廊 | 守住門口 | 一次只有一隻能貼身 | 無 |
| 櫃子、貨架、冰箱 | 推倒 | 砸到「近」的敵人，或擋住路讓牠們多走一回合 | 大 |
| 沙發、櫃台、車 | 躲到後面 | 人類敵人的槍打不準 | 無 |
| 椅子、滅火器、鍋子 | 拿起來用 | 臨時武器。滅火器可以噴，牠們一回合看不到也聽不清 | 中 |
| 窗戶、櫃台 | 翻過去 | 不用擲骰子的逃跑路線，但只有一個人過得去一回合 | 中 |
| 玻璃、車子、收音機 | 弄出聲音 | 把還沒貼上來的敵人引到那邊去 | 大 |
| 瓦斯爐、汽油 | 點火 | 燒。腫脹者只有這樣殺才安全 | 大 |
| 電燈開關 | 關燈 | 人類敵人打不準，疾走者不受影響 | 無 |

每件家具在資料裡標它能做什麼（門、可推倒、可躲、可丟、會響、可燃）。這也是家具必須做成真的立體方塊的原因。

### 聲音在戰鬥裡（預設）

聲音是「突然闖入的喪屍」這個變量的來源：闖進來的不是亂數，是被你剛才的動作叫來的。

每個指令都有聲音。畫面上有一條聲音條，還會標出「現在這個音量，哪些敵人聽得到」。安靜地打（刀、推開、關門）和大聲地打（槍、推倒櫃子）是每一回合的選擇。

### 敵人種類（提案）

文字版只有三種感染者加人類，畫面上會太單薄。兩個方向：

**同一種行為、不同身分**（便宜，符合設定集「看得出原本是誰」的原則）：

| 身分 | 差別 | 身上有什麼 |
|---|---|---|
| 一般居民 | 基準 | 隨機 |
| 護士、醫生 | 無 | 繃帶、藥 |
| 警察 | 防彈背心，打身體傷害減半 | 子彈 |
| 工人、外送員 | 安全帽，打頭無效，要先打掉 | 工具 |
| 學生 | 血少 | 零食 |
| 超市店員 | 無 | 食物 |

**新的行為**（貴，每種都要規則和美術）：

| 名稱 | 行為 |
|---|---|
| 抓人的 | 抓住一個人不放，被抓的人不能動，要別人來救 |
| 尖叫的 | 自己不打人，但會叫，一叫整條街都聽到。要先殺 |
| 爬的 | 沒有腿，藏在床底和車底。走近才看得到，取代文字版的「埋伏」 |

## 六、搜索（預設）

從「搜這個房間」改成「搜這樣東西」。

- 每個房間有 5 到 10 個可以互動的東西：冰箱、抽屜、衣櫃、屍體、背包、手機、便條。
- 每樣東西有自己的時間（2 到 10 分鐘）、聲音、狀態（開著、鎖著、卡住）。
- **物資總量不變**。規則照文字版算出這個房間有什麼，再分配到各個容器裡。平衡不用重調。
- 鎖著的可以撬（大聲）、找鑰匙、或叫有技能的隊友開。
- 有搜索技能的隊友在場時，有東西的容器會有提示。
- 隊友可以分頭搜：指一個容器叫他去翻。

**能讀的東西**是最便宜的細節來源：冰箱上的行事曆、手機裡沒送出的訊息、門上的便條、病歷、值班表。它們是文字，不吃美術。文字版的情報系統（哪裡有什麼、哪裡危險）也可以從這些東西給，不再只靠聊天。

## 七、人物（預設）

### 對話場景

文字版「聊天一小時換一條情報」改成有立繪的對話。每位生存者要有：

| 內容 | 數量 |
|---|---|
| 相遇場景 | 1 段 |
| 隨信任解鎖的對話 | 2 到 3 段 |
| 請託 | 1 個（文字版已有） |
| 性格發作的事件 | 1 個（文字版已有規則，要寫成場景） |
| 戰鬥中和走路時的短句 | 每人一二十句 |

故事和語氣在 `WORLD_BIBLE.md`，缺的是台詞。

### 隊友跟在後面

隊友在地圖上跟著主角走，最多三人（護送目標四人）。可以叫他在這裡等（文字版的留守）、去搜某樣東西。

### 符婕

她會來，也會走，不加入隊伍。事件的寫法另外定。

## 八、據點（預設）

- 佔一個房間當據點，沿用文字版的條件。
- 加固是看得見的：每加固一級，就多一扇門窗釘上木板。
- 晚上的襲擊是真的走到門口撞門。在據點裡時牠們要先破門，和文字版一樣。
- 第七天起掠奪者會來搜刮，沿用。

## 十、規則和畫面怎麼分工

文字版的原則是「Python 當裁判」，這點不變。但空間搬到畫面那一邊：

| 歸 Godot | 歸 Python 規則 |
|---|---|
| 位置、碰撞、走路 | 時間、飢渴、疲勞、感染 |
| 誰聽到了誰（聲音半徑） | 聲音的大小、地區威脅值、湧入 |
| 距離帶的畫面呈現 | 距離帶的數值、命中、傷害、被咬 |
| 環境物件在哪、能不能用 | 環境指令的效果 |
| 鏡頭、淡出屋頂、演出 | 物資生成、容器裡有什麼 |
| 對話的呈現 | 信任、請託、性格發作、情報 |

**Python 這邊要改的**（照改動大小排）：

1. 戰鬥的輪流方式：從「玩家、隊友、敵人」三段改成每個單位各自輪到。隊友的自動行動改成接受指令，自動的那套留給「他不聽話」的時候用。
2. 新指令：打腿、掩護、環境指令、技能指令。
3. 物資分配到容器。
4. 時間改成由畫面端回報「走了多遠」「做了什麼」。
5. 發現與潛行從擲骰子改成由畫面端回報「牠聽到了」。
6. 每天早上的存檔點。

現有的 28 項測試裡，戰鬥相關的要跟著改寫。生存數值、物資、隊友、據點、結局的測試照舊有效。

## 十二、風險

- **美術量**。89 間房、七套套件、十五條街，加上敵人的身分變體。這是整個計畫最大的一塊，進度取決於美術供應。一圈一圈做是為了隨時可以停在一個完整的狀態。
- **一張圖的效能沒有量過**。
- **戰鬥規則幾乎重寫**。文字版的平衡是用機器人跑出來的，新的戰鬥要重新跑。
- **階段 1 還沒過**。有顯示卡的電腦上還沒有人看過畫面。內容量產要等那一關過了再開始。
